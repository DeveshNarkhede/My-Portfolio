🚀 Portfolio Project — 
Step 1 Setup

📌 Project Initialization - This portfolio project was initialized using **Vite + React** with JavaScript.
### ✅ Create project

npm create vite@latest my-portfolio

✅ Selected options
Framework → React
Variant → JavaScript

✅ Install dependencies

cd my-portfolio
npm install

## 📁 Folder Structure (Step 1) After project setup, the following folders were created to organize the application:
src/
 ├─ data/
 ├─ components/
 └─ sections/
